Рівень 2

Варіант 1 - Лабіринт

Дано лабіринт у формі двійкової прямокутної матриці, потрібно знайти найкоротший шлях у лабіринті від заданої точки до вказаного пункту призначення.

Шлях будуємо з використанням комірок, які містіть 1. В будь-який момент ми можемо рухатися лише на один крок в одному з чотирьох напрямків:
Go Top: (x, y) ——> (x – 1, y)
Go Left: (x, y) ——> (x, y – 1)
Go Down: (x, y) ——> (x + 1, y)
Go Right: (x, y) ——> (x, y + 1)

Результуючий файл містить значення найкоротшого шляху від початкової точки до точки призначення
