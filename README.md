Рівень 3

Варіант 1

Для заданого бінарного дерева та конкретної вершини в цьому дереві потрібно реалізувати функцію пошуку наступного елемента під час серединного проходу (in-order traversal).

Наступник - це вузол, який має значення більше за заданий вузол і знаходиться найближче до нього при серединному обході.

Функція отримує на вхід корінь бінарного дерева та вершину, для якої потрібно знайти
наступника.
